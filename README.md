
# HRGenius

An enterprise-oriented Human Resource Management System.

## Technology Stack

- Backend: Java 21, Spring Boot, Spring Security
- Frontend: React, TypeScript, Vite
- Database: MySQL 8
- Database Migrations: Flyway
- Authentication: JWT
- Build Tool: Maven
- Testing: JUnit 5, Mockito, Vitest, React Testing Library
- DevOps: Docker, GitHub Actions

## Architecture

HRGenius follows a modular monolith architecture.

## Project Status

Development in progress.
